01主营业务

三类业务

娱乐内容、体育与体验业务拥有不同的成本和周期。

应分部分析，避免用流媒体收入增长掩盖电视利润下降。

02收入来源

变现方式

用户订阅、广告主投放、影院与授权收入，以及游客消费共同构成收入。

IP 的跨场景变现是研究核心。

02 / COMPETITIVE ADVANTAGE

行业与护城河

IP 与目的地

迪士尼 · 4 个分析维度 · 研究判断与观察框架

03护城河

IP 与目的地

知名角色与乐园体验难以快速复制，但内容成功具有不确定性，IP 库并不自动保证每年都有爆款。

04增长驱动

增长来源

研究判断：流媒体盈利改善和乐园容量增加具有机会，但新增容量应与新增投入和游客需求配对。

05规模与成本

规模效率

全球发行可以分摊内容成本，重资产乐园则需要持续维护。

评估时不能只看会计摊销而忽略真实资本支出。

06品牌与信任

品牌与体验

家庭信任和角色情感是品牌基础。

提价若损害满意度或复游率，会把短期利润换成长期需求压力。

估值与回报测算

每股盈利情景 · 改变假设，检验价格与回报的关系

起始投资归一为 100；每股增长已包含净股数变化，不额外叠加回购。现金分配按初始投资的固定比例逐年累加、不再投资。默认倍数与增长均为情景，不是当前估值。

期末价格指数 = 100 × (1 + 每股增长)^年数 × 退出倍数 ÷ 买入倍数；期末总财富加上累计现金分配。年化财富增长由总财富反推，不是逐期现金流 IRR。

调整任一参数后即时重算。负回报表示本金损失；模型没有为估值结果赋予实现概率。
